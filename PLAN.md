# Unisocials — Event Ticket Selling Site

## Architecture
Multi-page universal site for students across all universities in Nigeria to buy event tickets.

## Pages
1. **index.html** — Home page (Hero with upcoming events, stats, featured events)
2. **events.html** — All events listing with ticket purchase
3. **pricing.html** — Ticket packages/pricing for different event tiers
4. **about.html** — About Unisocials
5. **faq.html** — FAQ about events and ticketing
6. **contact.html** — Contact page

## Navigation (shared across all pages)
Links: Home | Events | Pricing | About | FAQ | Contact
Buttons: Sign In | Buy Tickets

## Shared Assets
- `templatemo-622-clearwave.css` — Shared styling (updated tokens for UNN theme)
- `templatemo-622-clearwave.js` — Shared JS (modified for multi-page, no smooth-scroll for internal links)
