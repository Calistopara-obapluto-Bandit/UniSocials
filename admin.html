Create fixed-amount coupons. Example: ₦4,000 ticket − ₦400 coupon = ₦3,600 to pay.

🎤 Manage Events

Add or remove events. New events appear instantly on the Events page, Tickets page, and Home page for buyers.

🏛 Universities Manager

Add or remove universities. Each university has its own categories used across the site. Events and tickets are scoped per university.

Users who opted in to receive event notifications. When you create an event, subscribers of that university are emailed automatically.

🔑 Sub-Admins

Create staff accounts that can only do gate check-in and add events. Sub-admins cannot view orders or manage universities/subscribers.

📣 Influencers

🔐 Event Authorization

Choose the exact existing event and the exact Influencer Admin who should oversee its ticket sales.

🔐 Authorize Event to Influencer Admin

Select a real existing event and the exact Influencer Admin who should oversee its sales.

👥 Dedicated Staff Accounts

Create separate login accounts for Check-in Staff and Influencer Admins. Each account only gets its assigned dashboard.
