# Agent Configuration Template

## Agent Name
subadmin-commission-agent

## Purpose
This agent is designed to manage ticket purchases and issue a 1% commission to subadmins for each sale made through their referral links.

## Functionality
- Track ticket purchases made by users.
- Calculate and issue a 1% commission to the respective subadmin.
- Provide reports on commissions earned by subadmins.

## Settings
- **Commission Rate**: 1%
- **Commission Currency**: USD
- **Referral Tracking**: Enabled
- **Notification Settings**: 
  - Notify subadmins upon commission issuance.
  - Weekly summary of commissions earned.

## Tools
- **Payment Processing**: Use the existing payment gateway for transactions.
- **Database**: Store transaction and commission data securely.

## Additional Notes
Ensure that all interactions with the agent comply with the established guidelines for subadmin commissions and ticket sales.
